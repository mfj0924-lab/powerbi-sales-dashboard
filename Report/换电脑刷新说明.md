# 换电脑后，请修改一个目录参数再刷新。

请把 `销售分析.xlsx` 和 `源数据预期结果.json` 一起放到同一个文件夹。JSON保存独立从源Excel整理的预期数据，供隐藏的“关键数值检查”页对照使用。

在Power BI中选择“主页 → 转换数据”，进入Power Query后选择“主页 → 管理参数”，把 `DataSourceDirPath` 改为两份文件所在的文件夹路径。然后选择“关闭并应用”，再刷新并保存报告。

本项目中的数据文件位于作业根目录下的 `PBI项目实战作业/项目实战作业/Data/销售分析`。提交或复制时，两份文件都需要带上。Report/验收中的同名JSON是开发记录副本，当前模型已经不再读取它。

2026-10-10已在本机的另一个目录实测：仅修改DataSourceDirPath，整个模型刷新成功；事实表与检查表各1056行，检查差异为0。已恢复原目录。此测试证明换目录读取正常，没有在第二台电脑上测试。

如果修改了源Excel中的业务数据，需要重新独立生成并核对预期JSON，再更新同文件夹中的JSON；不要把当前检查结果直接复制成预期值。

参数用来集中保存目录地址。这一用法可参阅[微软Power Query参数文档](https://learn.microsoft.com/en-us/power-query/power-query-query-parameters)。
